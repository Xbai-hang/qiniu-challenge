# 一、产品视觉定位

本产品并非传统 Calendar App。

而是：

# AI Native Productivity OS

核心理念：

- AI 是第一入口
    
- 日历只是 AI 的一个操作界面
    
- 用户通过自然语言驱动系统
    
- 整个界面应表现为：
    
    - 安静
        
    - 柔和
        
    - 有空间感
        
    - 低认知负担
        
    - 像 AI 在后台持续思考

# 十一、动画规范

## 动画原则

产品动画必须：

- 缓慢
    
- 柔和
    
- 有惯性
    
- 有呼吸感
    

禁止：

- 生硬闪动
    
- 高频动画
    
- 机械过渡
    

---

# 推荐 Transition

```css
transition:
all 0.35s cubic-bezier(
0.4,
0,
0.2,
1
);
```

# 二十三、推荐交互感

产品应该让用户感觉：

```txt
AI 在后台持续工作
而不是等待用户点击
```

因此：

- 动画要轻
    
- 卡片要漂浮
    
- Tool Call 要实时
    
- Timeline 要动态
    
- AI Thinking 要持续反馈
    

---

# 二十四、禁止事项

禁止：

- 传统后台管理风格
    
- 强边框
    
- 高饱和蓝
    
- 信息过密
    
- 表格化布局
    
- 机械 hover
    
- 复杂表单
